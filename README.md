# Js-Mini-Projects

A collection of simple JavaScript projects created for learning and practice.

---

## 1. To-Do Project
A simple JavaScript To-Do application.

### ✨ Features
- Add/Delete tasks
- Pending task counter
- Strike-through for completed tasks

### 🚀 How to Run
1. Go to folder `1 To-Do Project`
2. Open `todo.html` in browser

### 📌 Future Improvements
- LocalStorage support

---

## 2. Quiz Game
A multiple-choice quiz game about India’s national symbols.

### ✨ Features
- Dynamic question loading
- Option buttons with green/red feedback
- Next button navigation
- Score counter
- Progress tracker (“Question X of Y”)

### 🚀 How to Run
1. Go to folder `2 Quiz Game`
2. Open `quiz.html` in browser

### 📌 Future Improvements
- Shuffle options
- Restart button
- Timer per question
