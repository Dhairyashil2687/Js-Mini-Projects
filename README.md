## 1. To-Do Project
A simple JavaScript To-Do application.

# Features
- Add/Delete tasks
- Pending task counter
- Strike-through for completed tasks

# How to Run
1. Go to folder `1 To-Do Project`
2. Open `todo.html` in browser
